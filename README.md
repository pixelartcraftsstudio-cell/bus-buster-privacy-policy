# Bus Buster Privacy Policy

This repository contains the privacy policy for the **Bus Buster** mobile game.

## Public policy page

After GitHub Pages is enabled and deployed, the policy should be available at:

https://pixelartcraftsstudio-cell.github.io/bus-buster-privacy-policy/

## Files

- `index.html` — formatted, mobile-friendly page for GitHub Pages
- `PRIVACY_POLICY.md` — Markdown copy of the policy

## Enable GitHub Pages

In the repository, open **Settings → Pages** and choose **Deploy from a branch**, select `main` and `/(root)`, then save. GitHub Pages may take a few minutes to publish the page.

Before submitting the URL to Google Play, ensure the policy reflects the actual data collection and third-party SDKs used by the published game.
